Data exchange

Import & export

Bring in school data from Excel or download backup and report files.

Import teacher workload list (recommended)

Enter each teacher only once. Put all classes taught by that teacher in the Classes column, separated by commas. The weekly periods value applies to EACH listed class. The app expands the row into lesson assignments, then you can generate the timetable from this data.

Columns: Teacher Name | Subject | Classes | Periods per Week. Example: Ayub Muuse Cali | Physics | Form 1A, Form 1B, Form 1C, Form 1D, Form 2A, Form 2B, Form 2C | 3. This assigns 3 periods per week in EACH listed class. For PDF, use selectable text (not a scanned image). Review imported data before generating the timetable.

Import Excel workbook

Upload an .xlsx or .xls workbook. Supported sheets: Teachers, Classes, Subjects, Assignments, Rooms. Column headers should match the templates.

Excel support uses the SheetJS browser library loaded from a CDN, so internet access is required for XLSX import/export. CSV export and printing are built in.
